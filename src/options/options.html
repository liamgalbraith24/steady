Steady settings

Settings load from your Chrome profile.

Profiles

A profile is a set of settings. Keep several (for example "Morning" and "Evening") and switch between them from the Steady toolbar button.

Cursor smoothing

Steady draws its own smoothed cursor (the "ghost cursor"). Clicks go to where the ghost cursor is, not where the shaky system cursor is.

Further right = steadier. Technically the minimum cutoff frequency in Hz (lower is steadier).

Further right = less lag on big, deliberate movements, but more shake gets through.

Target assist

Dwell click

Click by holding the cursor still over a target. A ring fills up first so you can move away to cancel. Press Esc to cancel too.

How far the cursor can drift and still count as "holding still".

Second switch (select)

With one switch: a short press moves on, a long press selects. With two switches: the first moves on, the second selects.

Sites

Steady is off on these sites

    "One click = double click" is on for these sites

      Research study logging

      Off by default. When on, Steady records anonymous interaction events (for example "dwell click fired") on this computer only. Nothing is sent anywhere. The researcher exports the log from the Steady toolbar button.

      Back up or share settings

      Save all profiles to a file, for example to set up Steady on another computer.

      This replaces all profiles and site lists with Steady's defaults.

      Emergency off switch

      Press Ctrl + Shift + S to turn Steady off (or back on) in the current tab. The page will then work exactly as it does without Steady. You can change the shortcut at chrome://extensions/shortcuts.
